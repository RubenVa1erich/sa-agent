## Бизнес-домен

Финансовый агрегатор: клиент заполняет одну анкету в мобильном приложении, агрегатор
рассылает заявку в несколько банков-партнёров и показывает клиенту предложения.
Ключевые сущности: клиент, заявка (loan application), предложение банка (offer).

## Системная архитектура

| Компонент | Ответственность | Владелец данных | Команда |
|---|---|---|---|
| `mobile-app` | Клиентское приложение (iOS/Android) | — | Mobile |
| `api-gateway` | Аутентификация, маршрутизация, rate limiting | — | Platform |
| `application-service` | Приём и хранение заявок, статусная модель заявки | заявки | Loans |
| `partner-gateway` | Рассылка заявок в банки, приём ответов, маппинг форматов | запросы к партнёрам | Integrations |
| `offer-service` | Хранение и ранжирование предложений банков | предложения | Loans |
| `notification-service` | Push / SMS / email | — | Platform |

**Внешние системы / интеграции:**

| Система | Назначение | Протокол | Направление |
|---|---|---|---|
| Банки-партнёры (N шт.) | Рассмотрение заявок | REST (у каждого свой API), часть — callback | выход / вход |
| БКИ | Кредитная история | REST, mTLS | выход |

## Стек технологий

- Языки / фреймворки: Java 21 / Spring Boot, Kotlin (mobile)
- БД: PostgreSQL
- Брокеры: Kafka (доменные события), RabbitMQ (задачи partner-gateway)
- API gateway / авторизация: Kong, OAuth2 / JWT

## Соглашения команды

> Пусто = умолчания агента.

- Kafka-топики: `aggregator.<сущность>.<событие>.v<N>`

## Ключевые ограничения

- Регуляторные: 152-ФЗ — ПДн хранятся в РФ; согласие клиента на передачу данных в каждый банк и запрос в БКИ.
- Технические: банки-партнёры отвечают от 5 секунд до 24 часов.

## НФТ по умолчанию для проекта

- Доступность клиентских API: 99.9% / мес
- p95 синхронных клиентских API ≤ 500 мс
