# Прочие типы контрактов — общий шаблон

Для GraphQL, SOAP/WSDL, webhooks, файлового обмена (SFTP, S3), и всего, что не
REST/события/gRPC. Если для типа существует стандартный формат — сгенерировать его
в дополнение к описанию:

| Тип | Машиночитаемый формат |
|---|---|
| GraphQL | SDL (`.graphql`) |
| SOAP | WSDL + XSD (фрагменты; полный WSDL — если просили) |
| Webhooks | OpenAPI 3.1 `webhooks:` |
| Файловый обмен | JSON Schema / XSD / описание CSV-колонок |
| Иное | только Markdown-шаблон ниже |

## Для файлового обмена дополнительно
- Имя файла (маска), кодировка, разделитель, заголовок, формат дат и чисел
- Расписание, окно доставки, что если файла нет к сроку
- Подтверждение получения (ack-файл, квитанция)
- Повторная доставка и дубли (как определить дубль)
- Максимальный размер, частичная загрузка, архивирование

## Нефункциональные требования
