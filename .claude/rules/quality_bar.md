# Планка качества — самопроверка перед выдачей

Перед тем как показать артефакт аналитику, пройди этот список. Исправь найденное сам;
то, что исправить нельзя без данных — превращай в `[TODO]` и открытый вопрос.

## Любое требование

- [ ] **Атомарно** — одно утверждение. Нет «и/или», перечислений разнородных действий,
      «а также», «в том числе».
- [ ] **Однозначно** — нет слов без метрики: *быстро, удобно, по возможности,
      по необходимости, своевременно, достаточно, оптимально, гибко, надёжно, современный,
      интуитивный, и т.д., и прочее, как правило, при необходимости, большой, много*.
      Каждое — либо заменить метрикой, либо `[TODO: уточнить — метрика для «быстро»]`.
- [ ] **Проверяемо** — есть AC, по которому QA скажет «прошло/не прошло».
- [ ] **Трассируемо** — указан источник (БТ-ID, файл, тикет).
- [ ] **Приоритет** проставлен.
- [ ] Не содержит решения реализации, если это не осознанное ограничение
      («использовать Redis» — это ОГР, а не ФТ).

## Полнота

- [ ] Негативные сценарии: невалидный ввод, отсутствие прав, сущность не найдена,
      конфликт состояния, повтор запроса.
- [ ] Граничные значения: 0, пусто, максимум, ровно на границе, дробные суммы, часовые пояса.
- [ ] Недоступность зависимостей: таймаут, 5xx, частичный ответ.
- [ ] Конкурентность: два одновременных запроса на одну сущность.
- [ ] Жизненный цикл: откуда сущность появилась, какие статусы, чем заканчивается.

## API / события

- [ ] Каждая операция имеет коды ошибок с описанием, когда возникают.
- [ ] Все поля: тип, обязательность, nullable, формат, ограничения (min/max/pattern/enum), пример.
- [ ] Идемпотентность описана для небезопасных операций.
- [ ] Версионирование и совместимость указаны.
- [ ] Соглашения проекта (naming, даты, деньги) соблюдены единообразно.

## Документ

- [ ] Все допущения и TODO собраны в «Открытые вопросы».
- [ ] Нумерация не конфликтует с `trace.md`.
- [ ] Нет противоречий между разделами (одно поле — один тип везде, одна сущность — одно имя).
- [ ] Нет «воды»: каждый абзац несёт информацию.
